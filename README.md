# CasinoStrat
Roulette-Taktik: 5€ setzen. Wenn gewonnen, wieder 5€ setzen. Wenn verloren, Einsatz verdoppeln. Funktioniert das wirklich. Das findet dieses Programm heraus.
Generell lassen sich Gewinne erzielen, bis irgendwann mehrere male hintereinander alles verloren wurde und der Kontostand bei 0 ist.

**Keine einzige Zeile Code** in diesem Projekt wurde mithilfe von AI erstellt.
